# re_ucm_ficbook

Модуль поддержки портала [Ficbook (Книга Фанфиков)](https://ficbook.net) для ReUltimateCopyManager.

Реализует интерфейсы `Portal` и `PortalService` из [re_ucm_core](../re_ucm_core/) с формированием структуры книги через [dart_book](https://github.com/BooksFine/dart_book).

## Особенности

- **Поддержка зеркал**: возможность настройки альтернативного зеркала сайта (например, `fanficlets.xyz`).
- **Многопоточная загрузка**: параллельное скачивание глав с настраиваемым количеством потоков.
- **Парсинг в изолятах**: парсинг HTML-разметки и очистка от рекламы выполняются в фоновых изолятах без блокировки UI.
- **Метаданные**: извлечение авторов, фэндомов, меток, статуса (завершен/в процессе) и обложек.
- **Загрузка ресурсов**: встроенный резолвер для изображений.

## Сборка

```bash
dart run build_runner build --delete-conflicting-outputs
```
